# CMPINF10_vsc_assignment
This is the shared repo that Pranav and Spencer are working in.

Our program asks the user for their name and their age.
If their age is negative we give a reference to a classic David Fincher film.
If their age is between 0 and 12 we tell them to bask in the joys of youth.
If their age is between 13 and 50 we warn them about a midlife crisis.
And if their age is over 50 we tell them they are going to DIE!
